## What this source matrix does not establish

The current router has 89 Route declarations (88 explicit paths plus a wildcard), and the page directory has 74 non-test TSX modules. Those counts include aliases, legacy redirects, embedded views and public/print/kiosk variants. They are inventory counts, not completed visual test cases or a claim that every business workflow has been examined to equal depth.

The five reviews do **not** establish a dedicated end-to-end audit for the following surfaces, even where they appear in route inventory, navigation, or a cited caller: Action Inbox internals; Admin Settings; Analytics outside the referenced reporting/dashboard behavior; Audit Log; BOM Unit Mismatches; Company Register/Register; Crew Station Kiosk and Operator Kiosk in full; Custom Fields; Customer Complaints/RMA; Customers; Estimate Workbench; Import Center in full; Job Costing; My Settings/SMS delivery; Not Found/Unauthorized in full; PO Upload; Platform Overview; Process Sheets; Shop Data; Users/User Approvals; Visitor Log beyond the sampled Add visit picker; Visitor Sign-in; TV Pairing/Wallboard; Work Centers configuration; and the five print pages (badges, packing slip, purchase order, shipping label, traveler). Source references to these surfaces are not a substitute for dedicated workflow coverage.

No source reviewer in these five reports performed production writes, customer/supplier sends, comprehensive assistive-technology testing, performance benchmarks, load testing, or a full security/compliance assessment. Request latency, cancellation races, partial results, hidden older records and multi-session state should be exercised with local/staging fixtures. Browser evidence collected separately can strengthen individual findings, but it should not silently upgrade unrelated source hypotheses to observed defects.

## Using the reviews for implementation

Keep each finding's concrete user outcome and acceptance criteria when creating work. Consolidate shared fixes—query identity/freshness, pending mutation state, human-readable entity pickers, overlay layering, and URL/dirty-form context—without erasing the distinct module regressions they must prevent. Retain the “already fixed” sections in every source review: they identify improvements present on current main that must not become duplicate tickets or be inadvertently regressed.
