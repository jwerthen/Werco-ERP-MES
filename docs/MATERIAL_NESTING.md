# Retired quoting subsystem

This document described the former quoting framework, which has been removed from the running ERP. New estimates use [Fabrication Quoting](FABRICATION_QUOTING.md).

Historical quote/source tables and migrations remain for retention; their old pricing and authoring services are no longer available. Production laser-nest import and dispatch are separate work-order functions and remain supported.

The former implementation and detailed documentation remain in Git history.
